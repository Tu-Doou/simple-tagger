# 创作分支（画面需求 ➔ tag / NL）

用户只给了文字需求、画面里只有一个主体时进入本分支。通用规则与命令见 SKILL.md。

## 一、拆需求

把用户的话拆到下面几栏（顺序即 tag 分组顺序）：

| 栏 | 内容 | 用户没说时 |
|---|---|---|
| 人数 | `1girl, solo` / `1boy, solo` | 按需求判断 |
| 角色 | 用户给的角色名、触发词、角色 tag 块 | 不写 |
| 外貌 | 发型发色、瞳色、体型 | 不补 |
| **服装** | 上衣、下装、鞋袜、饰品、手持物 | 补一组合理选择 |
| **姿势** | 站坐躺跪、手的位置、表情、视线 | 补一组合理选择 |
| **构图** | 景别、视角、主体朝向（`full body`、`cowboy shot`、`from above`……） | 补一组合理选择 |
| 场景 | 地点、时间、天气、光线 | 只写画面必需的 |

## 二、按需求的明确程度交付

| 用户说了多少 | 怎么交 |
|---|---|
| 很具体（「白发修女，黄昏废墟里跪地祈祷」） | 照着写一条，不加用户没说的设定 |
| 只有主体（「来个猫耳女仆」） | 补服装、姿势、构图交一条，下方一行说明补了什么 |
| 只有方向（「夏日清凉感」「随便来张」） | 给 2~3 条方案，差别放在服装、姿势、构图上 |

不要空手反问：信息再少也先交一版，下方一行说明可以怎么改。

## 三、查词

先凭经验写出整串草稿，用一次 `check` 批量比对；只对报「词表外」或拿不准的概念单独 `search`。

- 优先选帖子数高、含义正对的；同一概念的近义 tag 只选一个最贴切的；
- 查不到合适的 tag ➔ 改写进 NL。

## 四、成品示例

```text
1girl, solo,

white hair, long hair, red eyes,

nun, habit, veil, rosary,

kneeling, own hands clasped, looking up,

full body, from side,

ruins, church, dusk,
```

交付前自查：服装、姿势、构图三栏都有且拆到颜色/款式/视角一级；用户给的 tag 和特征都在，删改过的已在下方说明。
