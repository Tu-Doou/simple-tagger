# 快速反推（图片 ➔ tag）

目标：用最少的回合交出大体正确、比打标器原始输出好的 tag。不逐条查词，词表问题交给校验器 `--fix`。

## 流程

1. **打标**（与读本文件同一轮）：本地图片跑 `& $PY "$SKILL\tools\quick_tag.py" "<图片>"`；剪贴板粘贴、没有路径的图片在项目目录内跑 `& $PY "$SKILL\tools\quick_tag.py" --pasted`。退出码 1 ➔ 报错原样告诉用户（取图失败就请用户给本地路径），不要自己改走别的脚本。
   - 输出说「多人图」➔ 改走多角色模式，读 `references/多角色.md`、`references/通用规则.md`、`references/工具.md`。
2. **看图**：在同一条回复里同时发出全部局部图的 read（分开发，每张多一轮）；对话里还没见过原图（用户给的是路径）就把原图一起读。**不要另调 `crop.py`、`tag_vocab.py`、`pixai_tagger.py`，也不要写临时脚本读 `run.json`**（清单已带分数，局部图已切好）。
3. **写草稿**，按 SKILL.md「当前默认模型」的 tag 顺序分组，组间空一行：
   - 高档：默认留，画面上明显不符才删；
   - 中档：在图上确认看得见才留；
   - 低档：在图上看得见才留；
   - 打标器漏掉的（常见：景别、视角、手的动作、表情、背景）按 Danbooru 习惯直接写，不查词；
   - 槽位冲突选一个；主姿势只留一个；同义 tag 只留一个（`shoes` 与 `blue footwear` 留后者）；
   - 服装、姿势、构图拆到颜色、款式、视角一级；
   - 不写质量词、分级标签、画师名、人物名（人物候选放代码块下方）和画面上看不见的东西；
   - NL 只写左右手、人与物接触这类 tag 表达不了的，最多两句，主语用 she/he，一句一件事，不加修饰性副词；没有就不写。
4. **校验一次**：`& $PY "$SKILL\tools\anima_validate.py" --fix --tags "<分组草稿>" --nl "<NL，没有就省略>" --token-limit <token-limit>`。用户给了角色名或触发词时放进 `--user-tags`。
   - 退出码 0 ➔ 直接交付 `[最终文本]`，不要为了补回 `[已自动修正]` 删掉的 tag 再跑（复合 tag 校验器已自动拆开，拆不开的写进说明）；
   - 退出码 1 ➔ 只改 `[待处理]` 列出的项（槽位冲突、token、NL 句号），再跑一次。
5. **交付**：`[最终文本]` 原样放进 ```text 代码块。下方最多两行：人物候选；`[已自动修正]` 里删掉的、用户可能想自己补的概念；拿不准的项。
