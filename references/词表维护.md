# 词表维护

tag 词表放在 `vocab/`，当前生效的词表及其来源记录在 `vocab/manifest.json`：

```powershell
& $PY "$SKILL\tools\tag_vocab.py" info
```

格式为 a1111-sd-webui-tagcomplete 的 CSV：`name,category,post_count,"alias1,alias2"`（category：0 一般、1 画师、3 作品、4 角色、5 元数据）。

---

## 更新流程

用户说「更新词表到 xx 模型」「换个词表」时：

1. **找候选**：搜索 xx 模型训练所用的标签体系（Danbooru、e621 等）以及对应的 tagcomplete 格式词表。优先选：标签体系与模型一致、数据日期接近或晚于模型训练截止日期、上游仍在维护的。
2. **报给用户确认**：列出每个候选的来源链接、**数据日期**（上游最后更新日期或提交说明里的日期）、文件大小、为什么适合这个模型。等用户确认，**确认前不下载**。
3. **安装**：

   ```powershell
   & $PY "$SKILL\tools\tag_vocab.py" install "<raw 下载链接>" --model "<模型名>" --source-date "<数据日期>" --note "<上游仓库与提交说明>"
   ```

   工具会检查 CSV 格式，写入 `vocab/` 并更新 manifest；旧词表文件保留，只是不再生效。
4. **核对**：运行 `info` 确认生效，再用 `search` 抽查几个常用 tag。把安装结果告诉用户。

如果该模型在 [模型档案.md](模型档案.md) 里还没有一节，顺便按模板补上，并把「词表」一栏指向新词表。
