# 词表维护

tag 词表放在 `vocab/`，当前生效的词表及来源记录在 `vocab/manifest.json`。格式为 a1111-sd-webui-tagcomplete 的 CSV：`name,category,post_count,"alias1,alias2"`（category：0 一般、1 画师、3 作品、4 角色、5 元数据）。命令见 SKILL.md「工具」。

## 更新流程

1. **找候选**：搜索该模型训练所用的标签体系（Danbooru、e621 等）及对应的 tagcomplete 格式词表。优先选标签体系一致、数据日期接近或晚于模型训练截止日期、上游仍在维护的。
2. **报给用户确认**：列出每个候选的来源链接、**数据日期**、文件大小、为什么适合。**确认前不下载**。
3. **安装**：`tag_vocab.py install`，`--note` 写上游仓库与提交说明。工具会检查 CSV 格式、写入 `vocab/` 并更新 manifest；旧词表保留但不再生效。
4. **核对**：`info` 确认生效，`search` 抽查几个常用 tag，把结果告诉用户。

该模型在 [模型档案.md](模型档案.md) 里还没有一节时，按模板补上。
