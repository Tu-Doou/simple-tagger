由助手维护，只记录随模型变化的写法。当前默认模型写在 SKILL.md「当前默认模型」块；何时读、何时改见 SKILL.md「流程」第 1 步。

---

## Anima

| 项 | 写法 |
|---|---|
| input | Danbooru tag 为主，需要时在 tag 后空一行接英文 NL |
| 词表 | Danbooru 系（tagcomplete `danbooru.csv`） |
| token-limit | 512（T5 分词） |
| tag 顺序 | 人数 → 用户给的角色名/触发词 → 外貌 → 服装饰品 → 姿势表情 → 构图视角 → 场景；分组之间换行，行末保留逗号 |

**多角色**：官方建议角色名后紧跟基本外貌描述（[多角色模式.md](多角色模式.md) 的写法已满足）。

参考：[Anima 提示说明](https://huggingface.co/circlestone-labs/Anima#natural-language-prompting-tips)

**NL**：与 SKILL.md「NL」规则不同的地方（长度、句式、位置），附 ❌/✅ 对照；没有就省略。
